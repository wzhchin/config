# 会议文档结构模板库

本文件定义两类文档的标准模板：
1. `<prefix>-会议纪要.md`：根据会议类型从 4 套模板中选择最匹配的一套。
2. `<prefix>-讨论摘要.md`：统一按逻辑议题组织的深度摘要结构。

所有模板均遵循以下通用约定：
- 顶部保留 YAML Frontmatter，便于知识库（Obsidian / Notion / Git）检索。
- 关键结论与待办均附带时间戳锚点（如 `[00:18:40]`），便于回溯 `<prefix>-文字记录.md` 与原录音。
- 原文未提及的字段填 `待确认` 或 `未提及`，**严禁虚构**。

## 一、`<prefix>-会议纪要.md` 模板

### 通用头部（4 种会议类型共用）

```markdown
---
title: "<会议主题>"
date: "<YYYY-MM-DD，无法判断则填待确认>"
meeting_type: "<例会同步 | 需求方案评审 | 访谈调研 | 项目复盘>"
source_file: "<原始文件名>"
participants:
  - "<参会人/发言人1（角色）>"
  - "<参会人/发言人2（角色）>"
---

# <会议主题> - 会议纪要

> **关联文档**：[讨论摘要](./<prefix>-讨论摘要.md) | [清洗后文字记录](./<prefix>-文字记录.md)

## 会议信息

| 项目 | 内容 |
| :--- | :--- |
| **会议主题** | <主题> |
| **会议时间** | <日期/时间，未提及则填待确认> |
| **录音时长** | <如 01:12:35> |
| **会议类型** | <类型> |
| **参会人员** | <姓名/角色列表；若有匿名发言人注明“详见文字记录映射表”> |

## 一句话总结（TL;DR）

<2~3 句话概括本次会议的核心目的、最关键结论与下一步重心。>
```

## 二、`<prefix>-讨论摘要.md` 模板

用于承载会议中**所有有价值的讨论脉络、观点交锋与细节依据**，避免塞进纪要导致冗长，也避免只看逐字稿难以把握全局。

```markdown
---
title: "<会议主题> - 讨论摘要"
date: "<YYYY-MM-DD>"
source_file: "<原始文件名>"
---

# <会议主题> - 按议题讨论摘要

> **关联文档**：[会议纪要](./<prefix>-会议纪要.md) | [清洗后文字记录](./<prefix>-文字记录.md)

| :--- | :--- | :--- | :--- |

| 2 | <议题2名称> | `[00:15:20 - 00:38:10]` | `<已定论 | 部分共识 | 待跟进>` |
```
