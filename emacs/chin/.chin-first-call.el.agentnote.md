- 2026-09-01 eglot-performance
    - Problem
      Merge https://www.jamescherti.com/emacs-eglot-performance/ into this
      config without duplicating treesit/GC or adding packages.
    - Tried methods
      Mapped existing eglot/corfu/treesit/GC; checked Emacs 31.1 eglot.el
      defcustoms. pipe-max-size on this host is already 1 MiB.
    - Decision / rejected alternatives
      - Core knobs live in `with-eval-after-load 'eglot` so both
        `chin/dev-mode` and `SPC c a/r` autoload pick them up.
      - `read-process-output-max` 1 MiB in early-init (global process
        knob). Did not copy the article commenter's pipe-max-size snippet:
        it discards the proc value and always returns 1 MiB on gnu/linux.
      - Ignore on-type format, inlay, document-highlight, semantic tokens.
        Emacs 31 auto-enables inlay + semantic tokens on manage; treesit
        already fontifies. Code actions / rename / xref / eldoc stay.
      - Keep post-startup GC at 16 MiB. Article's 100 MiB would fight the
        emacs-startup-hook restore; no measurement to justify raising it.
      - Do not re-list `treesit-enabled-modes`.
      - Do not add gcmh, compile-angel, buffer-terminator, Company,
        Flycheck, or a global `eglot-workspace-configuration`.
      - Workspace ignore dirs (`node_modules`, build/) stay per-project
        `.dir-locals.el`.
