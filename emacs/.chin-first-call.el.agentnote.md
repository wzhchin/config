# chin-first-call 开发模式决策记录

- 2026-08-26 dev-mode
  - Problem: 直接调用 `evil-collection-xref-setup` 在完整配置批量加载中报 `void-function`；现有 `evil-collection` 版本没有可靠地提供该子模块的函数 autoload。
  - Tried method: 先依赖 `(require 'evil-collection)` 后直接调用 `evil-collection-xref-setup`；静态检查和替身函数测试通过，但实际 xref 初始化测试失败。
  - Problem: `chin-first-call.el` 原有的 `require 'evil-collection` 位于 `with-eval-after-load 'dired`，在 Dired 尚未加载时不会执行；因此 dev-mode 直接使用 `evil-collection-require` 仍报 `void-function`。
  - Decision: 移除 `evil-collection-xref` 自动初始化；改为在 xref 加载后手动绑定 `RET`/`<return>` 跳转、`n`/`p` 移动和 `q` 退出，并同时写入普通 keymap 与 Evil normal keymap。

- 2026-08-26 verification
  - Problem: 一次把多层 Emacs Lisp 嵌入 shell 的批量测试因括号不平衡报 `End of file during parsing`。
  - Fix: 将行为测试拆成单一职责的小表达式；随后命令调用、重复调用、非编程缓冲区边界和 xref 按键解析均通过。
